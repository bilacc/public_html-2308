# Public HTML 2308 Modernization

This branch introduces a modernized scaffold for a real estate website with a Node.js backend (Prisma) and React frontend. It includes:
- Basic monorepo layout with backend and frontend directories
- Prisma schema for Property, Agent, and Image
- Express server bootstrap with CORS and environment config
- Sample REST endpoints for properties
- Frontend scaffold with routes for listing and detail pages

Note: This is a starting scaffold. Further refinement and migrations will follow.
